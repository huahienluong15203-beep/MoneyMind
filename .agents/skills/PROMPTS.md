## 🛠️ Hướng Dẫn Sử Dụng Cho Developer & AI Agent

Khi bạn hoặc một AI Agent cần tìm hiểu hoặc phát triển một chức năng bất kỳ:
1. Mở file `SKILL.md` trong thư mục chức năng đó để nắm rõ kiến trúc backend, frontend, schema, model, SQL query và test case.
2. Nếu muốn tái tạo hoặc yêu cầu AI code thêm tính năng mới, copy prompt từ file `PROMPT.md` tương ứng để đưa vào ngữ cảnh AI.
